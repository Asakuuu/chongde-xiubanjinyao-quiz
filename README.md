# ❖ 修辦津要題庫測驗 ❖

**溫故知新，精進修辦資糧**

這是一份為各位發心修辦的夥伴所設計的數位學習小工具，內容源自崇德學院編著之《修辦津要 題庫版》。
將厚實的題庫轉化為隨手可得的測驗，希望能有效的幫助與陪伴大家~

---

## ✦ 功能介紹
* **二種測驗模式**：
    * **選擇題**：適合尚未開始背誦或相較不熟悉者溫習，透過選擇將題目與答案連結。
    * **填充題**：模擬真實考驗，檢測自己是否已將修辦津要深植於心。
* **錯題複習**：自動幫您記住答錯的題目，能針對錯題再次複習。
* **全局總覽**：透過攻克軌跡，清楚看見累積的智慧與進度。

---

## ✦ 如何使用

### 一、 線上即時測驗 (最推薦)
無需下載任何軟體，點擊下方連結即可開始：
👉 **[點我開啟測驗工具]** *(請在此處貼上你的 GitHub Pages 網址)*

### 二、 離線收藏與使用
若希望將此工具存放在電腦中，方便隨時開啟：
1. 點擊頁面右上方綠色的 **「Code」** 按鈕。
2. 選擇 **「Download ZIP」**。
3. 解壓縮後，打開資料夾，雙擊 **`index.html`**，即可在瀏覽器中開始使用。
