# ❖ 修辦津要題庫測驗 ❖

**溫故知新，精進修辦資糧**

這是一份小小的數位學習工具，其內容源自崇德學院編著之《修辦津要 題庫版》。

將400題題目轉化為隨機考題測驗，希望能有效地幫助與陪伴大家~

---

## ✦ 功能特色

* **二種測驗模式**：
  
    * **選擇題**：適合尚未開始背誦或較不熟悉者溫習，透過選項快速連結題意與答案。
    * **填充題**：模擬真實考驗，檢測自己是否已深植於心，訓練更紮實的記憶。
      
* **錯題複習**：系統會自動記住曾答錯的題目，幫助未來針對弱點加強複習。
* **全局總覽**：透過攻克軌跡，清楚看見自己一點一滴累積的智慧與進度。

### 一、 線上即時測驗 (最推薦)
無需安裝任何軟體，點擊下方連結即可開始修辦津要溫習：

### 二、 離線收藏與使用
若希望將此工具存放在電腦中，即便在離線狀態也能隨時開啟：
1. 點擊本頁面右上方綠色的 **「Code」** 按鈕。
2. 選擇 **「Download ZIP」** 下載壓縮檔。
3. 解壓縮後，打開資料夾，雙擊 **`index.html`**，即可在您的瀏覽器中開始使用。
